# Master Zeks — Web3 Portfolio

A responsive Next.js portfolio for Master Zeks.

## Customize

- Edit text, experience, and achievements in `app/page.tsx`.
- Add real X, LinkedIn, Telegram, and email details to the `links` object near the top of `app/page.tsx`.
- Replace placeholder work cards with links to published work.
- Edit colors and layout in `app/globals.css`.

## Run locally (optional)

Install Node.js 20+ and run:

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Deploy on Vercel

1. Upload the files and folders **inside this project folder** to your GitHub repository root (not the ZIP itself).
2. Go to https://vercel.com/new and sign up with GitHub.
3. Import the `master-zeks-portfolio` repository.
4. Leave Framework Preset as Next.js and Root Directory as `./`.
5. Click Deploy. Vercel will install dependencies and build your site.

**Note:** Review Vercel plan terms before using a free Hobby account for commercial client work. A custom domain is optional.
